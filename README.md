## 五档配置分别够谁用

先把话说死：1GB 那档是“能跑起来”，2GB 才是“能安心用”。

1GB / $21.99 这档适合一台 Debian 或 Ubuntu 的最小系统、一个 Hugo 静态站、一个 RSS 聚合脚本、一个 Telegram bot、一台跳板机。下单页有提示 Debian 11/12 建议至少 2G 内存，1G 套餐别选新版本系统，装老一点的发行版或者 Alpine 更稳。WordPress 不是不能跑，得自己加 1–2G swap。

2GB / $35.99 是这条产品线上性价比最平衡的一档。2 核 2G 跑 WordPress + MySQL + Nginx，或者跑三四个 Docker 容器，日常负载不会顶到天花板。35GB 硬盘放一个中小型站点加备份也够。

4GB / $59.99 往上开始进入“多服务”区间。3 核 4G、60GB 硬盘、7TB 月流量，可以同时挂几个站点、一个自建数据库、一套监控。6GB 和 8GB 两档给的是 CPU 核数和流量，8GB 款 7 核 20TB 月流量，适合多站点托管或者流量型应用，但到这个预算，已经该认真比较一下别家在同价位的线路质量了。

Ryzen-512MB 是个特殊选项。$26.99/年买到的内存只有 512MB，比 1GB 款还少，贵在 Ryzen 9 3900X 的单核性能和 NVMe 硬盘。跑编译、跑对单核敏感的小服务，它比 1GB 款顺手；跑内存吃紧的东西，它先倒下。

这一条直接决定了它适合谁：面向欧美访客的外贸站、跑国际业务的服务、纯学习和测试环境，它没有问题；访客主要在中国大陆、又特别在意晚高峰打开速度的项目，这个价位段不该在它身上找答案。

## 四个会真正卡住人的限制

**付款后默认不退款。** 官方政策是默认不退款、个案处理，账户里预充值的余额也不可退。这和 DMIT 那种“3 天内且流量不超过 30GB 全额退款（扣支付手续费）、30 天内按剩余价值退”的政策完全不同，也比 QQG.NET 的“年付活动套餐不支持退款”松不了多少。第一次用 RackNerd，先用测试 IP 确认路由，再决定付不付这一年。

**只有年付和两年付。** Specials 没有月付、没有季付。想先试一个月再决定，只能去买常规 KVM 的月付款，或者接受这一年的一次性支出。

**Linux 特价和 Windows 是两条线。** $21.99 这些套餐装的是 Linux 发行版，不能用 Windows。真要 Windows 得单独买 Windows VPS，2G 内存那款 $27.59/月、年付 $331.08，比特价年付款贵了一个量级。冲着“便宜 Windows”来的，这个方向不对。

**流量是月流量，不是年流量。** 3TB 指的是每月 3TB、每月重置，一年总量是 36TB。这个口径在低价 VPS 里是通用的，QQG.NET、DMIT 的套餐标注也都是月流量。真正要留意的是超额之后怎么处理，各家不一样：DMIT 的 T1 系列是超量后限速不断网，RackNerd 的超额策略官网没有统一说明，买大流量用途前先发工单问清楚。

还有两个藏在服务条款里的成本：取消服务要在续费日前至少 5 天提交工单，取消后数据立即删除，得先自己备份；账单逾期 3 天可能收 10% 滞纳金，到期 7 天仍未付款会被系统终止，数据无法恢复。

## 支付、开机和几个实操细节

结账页支持的付款方式是 PayPal、信用卡、Stripe 支付宝、银联卡、USDT/USDC 稳定币、Boleto 和电汇，没有微信支付。国内用户用支付宝最顺。

付款后一般几分钟内开通，IP 和 root 密码发到注册邮箱，也可以在自己的 ctrl 面板里看。面板支持重启、重装系统、HTML5 VNC 控制台、网络防火墙和一键应用，防火墙在流量到达服务器之前就过滤，配错了还能从 VNC 改回来。

开机后有几件事建议按顺序做：先改 root 密码，再 `apt update && apt upgrade -y`，然后换成密钥登录并关掉密码登录，用 ufw 只放行 22、80、443，1G 内存的机器加 1–2G swap，最后把网站和数据库定期备份到别的地方。服务条款写明 RackNerd 不对数据完整性负责，备份这件事只能自己兜。

IPv6 在洛杉矶和法国机房可以开工单免费申请，最多 100 个。IPv4 的更换政策官网没有明确写，有需要的话下单前发工单问，别默认能免费换。

## 常见问题

**流量是月还是年？**
月流量，每月重置。1GB 款的 3TB 是每月 3TB。

**折合每月的价格能按月付吗？**
不能。Specials 只有年付和两年付，月均价只是年费除以 12 的比较方式。

**第二年续费会涨吗？**
不会。官方 FAQ 写明特价套餐按购买时的价格终身续费。前提是没有取消、没有逾期。

**买了不满意能退吗？**
默认不退款，个案处理，账户余额也不可退。这是这条产品线最大的风险点，下单前用测试 IP 把路由测清楚。

**1G 内存够装什么系统？**
下单页提示 Debian 11/12 建议至少 2G 内存，1G 套餐更适合老版本发行版、Alpine 或者精简过的系统，跑 WordPress 要加 swap。

**能换 IP 吗？**
IPv6 在洛杉矶和法国机房可以工单免费申请，最多 100 个。IPv4 更换政策官网未明确，需要问客服。

**要不要先月付试一个月？**
Specials 没有月付。想先试只能买常规 KVM 的月付款（$17.99/月起），或者干脆先用官方测试 IP 分时段 ping 一遍再决定。
